# Gourav QA Portfolio

The portfolio homepage is composed in `src/App.jsx` from separate components in `src/components/` (header, hero, about, skills, experience, projects, approach, contact, theme picker, and footer). The resume page is implemented in `src/Resume.jsx`. Each page has its own small Vite HTML entry shell and React entry point; shared visual styles remain in `styles.css`.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`; the deployable site is generated in `dist/`.
